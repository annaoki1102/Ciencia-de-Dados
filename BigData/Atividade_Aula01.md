## 2. Objetivo da atividade

Nesta atividade, sua equipe deverá analisar um **problema real** e pensar como uma equipe de Ciência de Dados poderia utilizar dados para compreender a situação e apoiar uma decisão.

O objetivo não é desenvolver um sistema ou modelo de Machine Learning neste momento.

O objetivo é aprender a **pensar como um cientista de dados**:

> **Problema → Dados → Informação → Análise → Decisão → Benefício**

# 13. Os 5 Vs do Big Data

Analise o problema escolhido pela equipe.

| V | Pergunta | Resposta da equipe |
|---|---|---|
| **Volume** | Existe uma grande quantidade de dados? | Sim, cada aluno gera dados a cada semestre (notas, frequência, matrícula) |
| **Velocidade** | Os dados são gerados ou processados rapidamente? | Moderada — atualizados por semestre, não em tempo real |
| **Variedade** | Existem diferentes tipos ou formatos de dados? | Sim: notas numéricas, dados cadastrais, textos de justificativas de trancamento |
| **Veracidade** | Os dados podem apresentar erros ou problemas de qualidade? | Sim, cadastros desatualizados e justificativas incompletas |
| **Valor** | Os dados podem gerar algum benefício ou apoiar decisões? | Sim, apoiam diretamente ações de retenção de alunos |

### Qual dos 5 Vs é mais relevante para o problema?

> Valor

### Justifique

> Mesmo sem grande volume ou velocidade, o valor gerado é alto: dados relativamente simples já permitem identificar padrões de risco e agir a tempo de reter o aluno.

# 14. Mapa do Problema de Ciência de Dados

Complete o fluxo abaixo:

```text
┌─────────────────────┐
│       PROBLEMA      │
│  Evasão escolar     │
│  nos primeiros      │
│  semestres          │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│        DADOS        │
│  Notas, frequência, │
│  bolsa, trabalho,    │
│  deslocamento        │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│     INFORMAÇÕES     │
│  Semestre crítico e  │
│  perfil de risco     │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│       ANÁLISE       │
│  Descritiva,          │
│  comparativa e        │
│  temporal             │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│       DECISÃO       │
│  Programa de tutoria │
│  focado em risco      │
└──────────┬──────────┘
           ↓
┌─────────────────────┐
│      BENEFÍCIO      │
│  Menos evasão, mais  │
│  conclusões de curso │
└─────────────────────┘
```

### Resuma cada etapa

**Problema:**  
> Evasão escolar concentrada nos primeiros semestres

**Dados:**  
> Notas, frequência, bolsa, trabalho, deslocamento

**Informação:**  
> Semestre crítico e perfil de aluno em risco

**Análise:**  
> Descritiva, comparativa e temporal

**Decisão:**  
> Implementar tutoria direcionada aos alunos em risco

**Benefício:**  
> Redução da evasão e mais alunos concluindo o curso

# 17. Reflexão final

Responda individualmente ou em equipe:

> **Ter muitos dados significa necessariamente tomar boas decisões? Por quê?**

**Resposta:**

> Não necessariamente. Ter muitos dados não garante boas decisões se esses dados forem de baixa qualidade, mal interpretados ou não estiverem conectados a uma pergunta clara. É preciso saber qual pergunta se quer responder e analisar os dados corretamente — quantidade sem contexto e sem análise crítica pode até levar a decisões erradas.
